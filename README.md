# CivicOS — Сонгуулийн штабын ухаалаг хяналтын систем

Иргэн/өрхийн дата сан, газрын зураг, AI дэмжлэгийн шинжилгээ, багийн гүйцэтгэл,
даалгаврын хяналтыг нэг дор нэгтгэсэн систем.

## Юу хийдэг вэ

| Хэсэг | Тайлбар |
|---|---|
| **Хяналтын самбар** | KPI, 12 сарын хандлага, дэмжлэгийн бүтэц, дүүргийн харьцуулалт, AI тэргүүлэх өрх, багийн гүйцэтгэл, автомат дүгнэлт |
| **Газрын зураг** | Leaflet + OpenStreetMap. Бодит гудамж, байшин. Өрх бүр цэгээр, дэмжлэгээр өнгөтэй. Кластер / дулааны зураглал / хорооны бүс гэсэн 3 горим. Дүүрэг → хороо → гудамж → өрх хүртэл шүүнэ |
| **Өрхийн бүртгэл** | Хайлт, шүүлт, эрэмбэ, олон сонголт, нэмэх/засах/устгах, Excel экспорт |
| **Иргэд** | Нас, хүйс, боловсрол, мэргэжил, байр сууриар шүүх |
| **Төсөл хөтөлбөр** | Хамрагдалт ба дэмжлэгт үзүүлсэн нөлөө (AI магадлалын зөрүү) |
| **Санал гомдол** | Ангилал, хороогоор задлан, шийдвэрлэлтийн хяналт |
| **AI шинжилгээ** | Өрх бүрийн дэмжих магадлал, магадлалын тархалт, загварын хүчин зүйлс, тэргүүлэх зорилтот жагсаалт |
| **Хорооны стратеги** | Хороо бүрийн боломжийн оноо ба тодорхой зөвлөмж |
| **Багийн гүйцэтгэл** | Ухуулагч тус бүрийн хамрагдалт, эерэг хариу, зорилтын биелэлт |
| **Даалгавар** | Хүснэгт ба Канбан хэлбэрээр, хариуцагч/төлөв/явцаар |
| **Импорт / Экспорт** | Ямар ч багана бүхий CSV/XLSX-г багана тааруулж оруулна. Excel, CSV, JSON нөөцөөр татна |
| **Тохиргоо** | Хэрэглэгч ба эрх, AI загварын жин, Supabase холболт, дата сан |

## AI дэмжлэгийн загвар

Хар хайрцаг биш — **ил тод, жинлэсэн логистик оноолт**. 9 хүчин зүйл:

| Хүчин зүйл | Анхны жин |
|---|---|
| Мэдэгдсэн байр суурь | 2.45 |
| Намын хандлага | 1.15 |
| Уулзалтын үр дүн (сүүлийнх нь илүү жинтэй) | 1.05 |
| Хөтөлбөрийн оролцоо | 0.95 |
| Хорооны хандлага (хөршийн нөлөө) | 0.85 |
| Холбоо барилтын шинэлэг байдал | 0.55 |
| Өрхийн доторх нэгдэл | 0.32 |
| Суурьшлын тогтвор | 0.28 |
| Дата баталгаажилт | 0.22 |

Өрх бүрт: **магадлал %**, **итгэлцлийн түвшин**, **хүчин зүйл тус бүрийн эерэг/сөрөг
хувь нэмэр**, **тодорхой зөвлөмж** гарна. Жинг `Тохиргоо` хуудсаас гүйлгүүрээр өөрчилнө.

**Тэргүүлэх зорилтын оноо** = хөрвүүлэх боломж (50%-д ойр өрх хамгийн өндөр)
× өрхийн саналын жин × датаны хуучрал × шийдэгдээгүй гомдол.

## Ажиллуулах

Ямар ч сервер шаардлагагүй — статик файл.

```bash
python -m http.server 8744 --directory civic-os
```

Дараа нь `http://localhost:8744` руу ор.

## Дата хаана хадгалагдах вэ

**Анхдагчаар:** браузерын `localStorage` дотор. Өөр компьютерээс харагдахгүй,
браузерын кэш цэвэрлэвэл устана. Тиймээс тогтмол **JSON нөөц** ав
(`Импорт/Экспорт → Бүрэн нөөц`).

**Supabase холбосон үед:** бүх дата сервер дээр очиж, багийнхан зэрэг ажиллана.
`supabase-setup.sql`-г Supabase SQL Editor дээр ажиллуулаад, `Тохиргоо → Supabase`
хэсэгт Project URL ба anon key оруулна.

## Нэвтрэлт ба аюулгүй байдал

Анх нээхэд **админ бүртгэл үүсгэх** дэлгэц гарна. Нууц үг SHA-256 + salt хэлбэрээр
браузерт хадгалагдана (сэргээх боломжгүй — тэмдэглэж ав).

> **Анхаар:** Supabase холбогдоогүй байхад нэвтрэлт нь зөвхөн **браузер талд**
> ажиллана — техникийн мэдлэгтэй хүн үүнийг тойрч, тухайн браузерт хадгалагдсан
> датаг харах боломжтой. Энэ нь линкийг санамсаргүй нээсэн хүнээс хамгаалах
> түвшин. **Бодит хамгаалалт** нь Supabase-ийн нэвтрэлт + RLS дүрэм — хувийн
> мэдээлэл оруулахаасаа өмнө заавал Supabase-ээ холбо.

Мөн: линк нь нийтэд нээлттэй хаяг тул зөвхөн итгэлтэй хүнд дамжуулна.
`<meta name="robots" content="noindex">` тавьсан тул хайлтын системд гарахгүй.

## Импортын формат

Багана нь **ямар ч нэртэй** байж болно — оруулах үед автоматаар тааруулж,
буруу бол гараар өөрчилнө. `Импорт → Загвар файл татах` дээрээс жишээ Excel ав.

Тусгайлан анхаарах:
- **Дэмжлэгийн түвшин** — `0–5` тоо эсвэл `Бат дэмжигч / Дэмжигч / Эргэлзэгч / Хазайсан эсрэг / Эсрэг`
- **Хороо** — `12`, `12-р хороо` аль аль нь болно
- **Дүүрэг** — `Баянзүрх`, `Баянзүрх дүүрэг` аль аль нь болно
- **Огноо** — `YYYY-MM-DD`, `DD/MM/YYYY`, Excel огноо бүгд танигдана
- **Төрсөн он** — он (`1980`) эсвэл нас (`42`) аль аль нь болно
- **Координат** — хоосон бол тухайн хорооны төв цэгт автоматаар байрлуулна
- **Нэг мөр = нэг хүн** бол `Иргэний нэр` баганыг холбо; ижил өрхийн кодтой мөрүүд нэг өрх болж нэгдэнэ
