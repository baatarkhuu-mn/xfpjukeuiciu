# AilOS

Дотоод хэрэглээний вэб систем. Хандалт хязгаарлагдмал.

## Ажиллуулах

```bash
python -m http.server 8744
```

## Бүтэц

```
index.html              — интерфейс
assets/app.css          — загвар
assets/js/store.js      — дата давхарга
assets/js/ai.js         — оноолтын загвар
assets/js/charts.js     — SVG график
assets/js/io.js         — импорт / экспорт
assets/js/map.js        — газрын зураг (Leaflet)
assets/js/ui.js         — дүрслэл, форм
assets/js/main.js       — нэвтрэлт, эхлүүлэлт
supabase-setup.sql      — серверийн бэлтгэл
```

Дэлгэрэнгүй заавар: `ЗААВАР.md` (зөвхөн локал).
